# 17173 CMS-publisher

[![Version](https://img.shields.io/badge/version-1.4.1-blue.svg)]()
[![License](https://img.shields.io/badge/license-MIT-green.svg)]()

> 一键完成分类、标题、正文、图片、智能填充全流程，从 15 分钟手动操作压缩到 10 秒。

## 功能特性

### 核心自动化
- **智能分类**：自动定位分类，支持 ztree 组件异步加载
- **标题提取**：自动读取文件名或从正文提取加粗标题
- **来源/作者**：自动选择"厂商稿"来源，提取书名号内作者
- **正文排版**：保留加粗/字号，自动生成 `p-image` 居中图片样式
- **图片上传**：docx 内图片自动解压 → Blob → 注入上传控件 → URL 回填（支持多图并行）
- **智能填充**：一键触发 CMS AI 标签生成

### AI 智能审稿 (v1.4.1 新增)
集成 `ai_reviewer.js` 模块，发布前自动检测：
- **错别字检测**：覆盖 17173 游戏领域高频易错词（帐号/登陆、Buff/CD 等）
- **标点规范**：中英文标点混用、连续标点、省略号/破折号格式
- **语句通顺**：句子过长预警、"的的/了了"重复、缺主语语病
- **敏感词过滤**：私服、外挂、代练等合规检查
- **评分系统**：本体系采用「五维加权 + 红线熔断」评分模型，从内容价值、原创合规、结构规范、阅读体验、传播适配五个维度对稿件进行百分制量化评估，70 分以下自动拦截发布

## 安装使用

### 方案 A：Tampermonkey 油猴脚本 (推荐)
1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击油猴图标 → 添加新脚本
3. 复制 `17173厂商稿发布助手.user.js` 内容粘贴
4. 保存，访问 17173 CMS 后台即可看到按钮

### 方案 B：Chrome 扩展
1. 下载 `17173厂商稿发布助手-v1.4.1-扩展.zip`
2. 解压到任意文件夹
3. Chrome 地址栏输入 `chrome://extensions/`
4. 开启"开发者模式" → "加载已解压的扩展程序"
5. 选择解压后的文件夹

## 使用流程

1. 在 CMS 后台打开发布页面
2. 点击悬浮按钮 **「一键发布稿件」**
3. 选择本地 `.docx` 文件
4. 脚本自动执行 8 步流程：
   ```
   分类选择 → 标题填充 → 来源/作者 → 正文写入 
   → AI 智能填充 → 发布模板 → 图片上传 → AI 审稿
   ```
5. 审稿通过后自动发布；不通过弹出修改建议

## 适配环境

- **CMS 地址**：`https://g.17173.com/`
- **浏览器**：Chrome 90+ / Edge 90+ / Firefox (Tampermonkey)
- **稿件类型**：厂商合作供稿、游戏评测、行业新闻

## 技术实现

- **docx 解析**：Mammoth.js (HTML) + DecompressionStream (原生解压)
- **CMS 交互**：jQuery trigger 模拟点击 + ztree API + MutationObserver 异步等待
- **图片处理**：内存 Blob → DataTransfer 注入 → 上传监听 → URL 回填
